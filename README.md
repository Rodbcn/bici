# Bici

Web app (PWA) para entrenar con una bici estática con Bluetooth FTMS (probada con adidas ONE C-24c)
desde Chrome en Android.

- Datos en directo: potencia, cadencia, velocidad, distancia, calorías, pulso.
- Entrenamientos por niveles de resistencia, adaptables a la duración elegida.
- Editor de entrenamientos propios, rodar libre e historial (guardado solo en el móvil).

Funciona solo en navegadores con Web Bluetooth (Chrome/Edge en Android, escritorio).
